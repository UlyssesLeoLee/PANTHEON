## 1. 交付范围与角色

本资料为从零开发的**设计与测试设计包**，不是已实现软件、执行过的测试报告或IPA官方认可证书。面向产品负责人、架构师、Rust/Tauri工程师、Next.js前端、DBA、QA、信息安全负责人。未经评审的时间和性能参数属于**拟定验收目标**，需要在架构评审会上确认。

**产品定位**：继承A5:SQL Mk-2强调的轻量SQL与ER生产力，把数据库结构、ER图、设计书、变更审批、测试证据、AI辅助连成闭环。不是重型企业数据库代理，不内置生产数据库超级用户。

**P0（首发范围）**：Windows 11 x64桌面；PostgreSQL/MySQL/SQLite/SQL Server；连接与元数据；SQL编辑与安全执行；数据网格；ER逆向与轻量正向草拟；Diff/迁移计划/人工批准；CSV/XLSX/表定义书；AI（可选、显式同意）；审计、备份。**P1**：Git/GitGit连接、批处理、插件、CLI、漂移监测、macOS/Linux；**P2**：Oracle适配、实时多人协作、私有团队服务、跨团队审批。P1/P2的需求保留但不作为P0上线阻断项。

## 4. 版本冻结与变更控制

1. 评审后把本包保存为`design-baseline/1.0.0`，任何变更通过`CR-YYYY-NNN`登记。
2. FR/NFR、接口、画面、实体、错误与测试分别有不可复用ID；删除须保留废止记录。
3. P0新增/变更必须同时更新需求、基本设计、详细设计、测试、Excel追踪；不得只改代码。
4. 测试状态全部为“未执行”；设计完备性不等于产品质量合格。
5. 不设未经确认的“支持任意DB”和“AI全自动安全执行”承诺。

## 5. 名词与边界

- **连接/Connection**：用户终端向目标DB直接连接；凭据保留本机。
- **设计态**：ER逻辑名、布局、迁移草稿；**实态**：实际数据库元数据。
- **快照**：元数据规范化产物，不是数据库数据备份。
- **预演**：在隔离测试数据库执行或验证计划，不保证生产零风险。
- **AI建议**：不可信候选，必须经过用户同意、结构验证和手工执行。
- **GitGit**：可选外部版本管理适配；本地版本不依赖其在线可用。
