## 风险与设计决策

1. **只读保护**：双层策略（SQLite READ_ONLY 连接 + `query_only`），增加 SQL 动词与 SQLite prepared statement readonly 验证。不构成任意 SQL 的安全沙箱。
2. **数据库适配**：下一阶段将适配器抽象为 `DbDriver`，不同数据库的事务、元数据、执行计划、权限与 DDL 语义分别实现，不采用不可靠的纯字符串转换。
3. **执行控制**：API 最多返回 1000 行，查询长于 5 秒时由 SQLite progress hook 中止；大型结果集下一阶段使用游标与流式分页。
4. **凭据**：当前仅 localhost Bearer Token 环境变量；下阶段升级为 OS credential store + 连接配置加密 + 审计与密钥轮换。
5. **前端呈现**：v0.1 ER 网格布局面向演示及少量表，复杂数据模型需使用图布局引擎及视口虚拟化。
6. **Tauri**：外壳不负责自动拉起 API，需设计 sidecar 进程管理、签名与升级通路后才可发正式发行物。
